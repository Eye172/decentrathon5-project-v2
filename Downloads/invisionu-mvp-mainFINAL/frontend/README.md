# Frontend (inVision U)

Полная документация по проекту, бэкенду и переменным окружения — в **[README в корне репозитория](../README.md)**.

## Команды

```bash
npm install    # зависимости
npm run dev    # http://localhost:5173 — прокси /api → http://127.0.0.1:8000
npm run build  # сборка в dist/
npm run preview
npm run lint
```

Для продакшена при отдельном URL API задайте `VITE_API_BASE_URL` перед `npm run build` (см. корневой README).
