# inVision U: fictional application fixtures and interface recording

The retained profile, life-map, event-editor and essay images show actual local
application forms populated with explicitly fictional demonstration details.
The interface image and architectural diagrams belong to the retained project
presentation. They do not establish a measured assessment result.

## New interface tour — 12 October 2026

`media/invisionu-interface-tour.mp4` is a new, silent 24-second walkthrough of
the original public Decentrathon implementation in an isolated local checkout.
It shows a fresh fictional Demo Applicant profile, an event editor, seven written
fictional life events (including a setback), and a focused-response prompt.

No essay is submitted, no interview is recorded, no provider is called and no
person receives an assessment or admissions decision. The prompt follows the
deterministic fallback, despite the prototype interface's AI label. Captured
browser frames are assembled into a readable tour, not a latency measurement.

`media/demo-preview.jpg` and the three `invisionu-tour-*.jpg` files are genuine
captures of those views. No original competition demo video was found across the
retained source branches. The new tour is dated separately from the hackathon.

[TECHNICAL.md](TECHNICAL.md) documents the implementation and the unvalidated
marketing/psychometric labels in the older prototype. Authentication is based
on opaque session tokens. The case study follows the team's confirmed equal
engineering roles rather than older per-person prose in a project copy.
