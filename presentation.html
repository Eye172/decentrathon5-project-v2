03 / ИИ И ДАННЫЕ КАНДИДАТА
Многомодальный разбор
Цель — снизить обход через ChatGPT: глаза и лицо ловят зачитывание с экрана, текст — «слишком гладкий» AI-стиль в эссе и в ответах.
1
Эссе и тексты — AI-детектор и эвристики по мотивационному письму; отдельно API /api/analyze для разбора произвольного текста. Это сигнал для комиссии, не автоматический отказ.
2
SJT + анкета · Life Map — структурированные и ситуативные ответы; идут в общий профиль для скоринга.
3
Live-интервью + мультиагентный скоринг — до 4 вопросов, транскрипты (Whisper). Бэкенд гоняет пайплайн invision_ai_core: отдельные смысловые блоки (путь, психология/устойчивость и мотивация, лидерство, оркестратор) — как в промптах backend/prompts/. На выходе — структурированный JSON для UI: по каждой оси свои метрики и текст, затем executive summary и балл из 100.
ВИДЕО
Непрерывная запись сессии (WebM), превью ~720p. Поведенческий отчёт по лицу передаётся на бэкенд вместе с интервью.
ВЗГЛЯД · ПРОТИВ «ЧТЕНИЯ С ИИ»
MediaPipe каждые 500 мс: направление взгляда, саккады (типичные паттерны при переводе взгляда на второй монитор / телефон / шпаргалку), контакт с камерой, синхронизация рта и речи. Комиссия видит метрики и текстовые выводы — чтобы отличить импровизацию от зачитывания готового текста.
ГОЛОС + ДЕТЕКТОР
Ответы только голосом (15 с подготовки, до 120 с на ответ). Озвучка вопросов (TTS) не даёт «прочитать параллельно» с тем же текстом на экране. После сессии — скоринг + baseline и сводный сигнал по эссе и всем транскриптам для честности отбора.

05 / СКОРИНГ
Сначала оси, потом вердикт
Модель не выдаёт один «чёрный» балл: для каждой компетенции считаются вклад в общую формулу и показываются объяснения — диалектика по пути, «гора» резилиентности, профиль лидера, анализ мотивации (SDT), карта аутентичности. В конце — краткий executive summary, итог из 100 и рекомендация (recommend / review / reject). Рядом для честности — rule-based baseline. Веса осей комиссия задаёт в настройках (сумма 100%).
